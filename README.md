# Breezy's Retro Hub

**One hub. Every system.**

Breezy's Retro Hub is an Android application designed to bring emulator management, game libraries, cheat discovery and system setup together in one place.

## Dev Build V1

This is the first development build under the Breezy's Retro Hub branding.

Previously developed as Breezy's Cheat Station and Retro Loader, the project is evolving into an all-in-one retro gaming companion.

### Current Development Foundation

- Nintendo 3DS emulator integration
- PlayStation 2 emulator integration
- Nintendo Wii and GameCube integration
- Game scanning and cheat discovery
- Configurable cheat repositories
- Emulator-specific cheat management
- Storage configuration and backups
- Navy, OLED Black and Grey Light themes
- Three illustrated icon packs:
  - Precision Outline
  - Soft Duotone
  - Retro Pixel

Feature availability and completeness vary by emulator.

## Our Vision

Breezy's Retro Hub aims to simplify the entire Android retro gaming experience.

Users will eventually be able to select their preferred consoles and use a guided Auto Setup process to discover, install and configure compatible emulators.

The goal is to reduce repetitive manual setup while keeping games, cheats and emulator settings accessible through one application.

## Planned Features

- Device compatibility detection
- Emulator discovery and installation assistance
- Guided and automated emulator configuration
- Unified multi-system game library
- Expanded cheat repository support
- Emulator-specific cheat installation adapters
- Automatic backups and recovery
- Artwork for 30 supported console identities
- Shared settings and storage management

Android security permissions and installation confirmations may still require user interaction.
