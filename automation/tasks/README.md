# Task queue

Create a new Markdown file such as `BUILD-004.md` here on `feature/retrohub-rebuild` to queue a Codex implementation. Each task should specify scope, acceptance criteria, compatibility and tests. The Termux worker polls for tasks every 180 seconds while running. No task is queued by this README.

Tasks are **code execution requests**. Only authorised repository writers should add or edit them. Review all task content before running the worker.
