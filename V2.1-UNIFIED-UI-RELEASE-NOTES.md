# Breezy's Retro Loader — v2.1 unified UI source release candidate

Based on the full-source export shared 2026-10-11. This archive contains a cumulative, directly extractable SOURCE patch, not an APK.

## Implemented
- Theme-aware base activity (`RetroThemedActivity`) applies one of three Android Material3 palettes before screen and dialog inflation: Navy / OLED Black / Grey Light. System bar foregrounds and backgrounds also follow the selected theme.
- Base activity recreates screens after returning from Appearance when theme, icon pack or system colour mode has changed.
- Runtime palette tokens for backgrounds, raised surfaces, primary and muted text, outlines, positive/negative/warning states, action buttons and icons.
- Removed conflicting hardcoded background and text colours from game lists, onboarding, cheat lists, cheat details, notices, home cards, Dolphin XML rows and empty states.
- Separate vector-rendered console illustration implementations for Precision Outline, Soft Duotone and Retro Pixel. Every pack supports 3DS, PS2, Wii, GameCube. Pixel pack has hand-authored 16x16 artwork (not merely disabled antialiasing).
- Icon-pack previews show all four consoles for each pack. Onboarding console choices now also use the same active icon pack.
- Shared press animations and optional haptic feedback wired to home cards, system settings navigation, game library rows, cheat detail toggles and onboarding selections. Theme-coloured selection marks/checkboxes and tabs.
- All pre-existing emulator detection, file scanning, storage permission, cheat repository, merge, backup and installation sources remain byte-identical to the uploaded original.
