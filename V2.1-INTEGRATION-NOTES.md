# Retro Loader v2.1 — UI integration patch (source overlay)

Applies against the uploaded Breezy-Current-Full-UI.tar.gz snapshot.

Changes: shared MaterialButton interaction (soft press + optional haptic), consistent selection row haptics and ticks, accessibility labels for console icon art, and common game/cheat detail navigation click feedback. Existing 3DS/PS2/Wii/GameCube scanning, storage, repository and installer code is unchanged. Existing three themes and three locally drawn console icon packs remain in place.

**Verification:** static source-level review only; this archive does not contain a complete Gradle project or wrapper. This is NOT a fully tested or complete screen-by-screen v2.1 redesign.

## Apply safely

```sh
cd ~/Breezys-Cheat-station
tar -czf ~/storage/downloads/RetroLoader-before-v2.1.tar.gz app/src/main
tar -xzf ~/storage/downloads/Breezy-Retro-Loader-v2.1-UI-integration.tar.gz
./gradlew assembleDebug
cp app/build/outputs/apk/debug/app-debug.apk ~/storage/downloads/BreezyCheatStation.apk
```

Only modified UI files are included.
